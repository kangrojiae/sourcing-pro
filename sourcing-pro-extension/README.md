# Sourcing Pro 수집기 (크롬 확장프로그램)

Sourcing Pro 화면에서 쿠팡·1688 링크를 넣고 **수집**을 누르면, 이 확장프로그램이
해당 상품 페이지를 보이지 않는 탭으로 열어 상품명, 가격, 썸네일, 옵션을 읽어 전달합니다.

앱 주소: https://claude.ai/code/artifact/f7a928bd-52ca-4a1d-a03a-dc272f1b365e

## 설치

1. 이 폴더를 고정된 위치에 둡니다. 폴더를 옮기면 확장프로그램이 해제됩니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력해 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다** 를 누르고 이 폴더를 선택합니다.

## 연결

설치만으로는 앱과 이어지지 않습니다. 한 번만 연결해주면 됩니다.

1. 위 앱 주소를 열어 로그인합니다.
2. 그 탭에서 크롬 툴바의 **Sourcing Pro 수집기** 아이콘을 누릅니다.
3. 팝업 맨 위 **Sourcing Pro 연결** 칸에 이 페이지 주소가 나타납니다. **연결** 을 누릅니다.
4. 크롬이 사이트 접근 권한을 물으면 허용합니다.
5. 앱 화면 왼쪽 아래가 **수집기 연결됨** 으로 바뀝니다. 바뀌지 않으면 페이지를 새로고침하세요.

연결한 주소는 크롬에 저장되어 다음 실행에도 유지됩니다. 팝업의 **해제** 로 언제든 끊을 수 있습니다.
앱이 화면 안쪽 프레임으로 열리는 경우에도 팝업이 그 프레임 주소까지 찾아서 목록에 보여줍니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `manifest.json` | 권한과 스크립트 등록. 앱 주소는 여기 적지 않고 팝업에서 동적으로 등록합니다. |
| `background.js` | 수집 요청을 받아 탭을 열고, 썸네일을 320px JPEG로 줄여 돌려줍니다. |
| `scrape.js` | 쿠팡·1688 페이지에서 실제 값을 읽습니다. 선택자, JSON-LD, og 메타 순으로 시도합니다. |
| `bridge.js` | 연결한 페이지에 주입되어 앱과 확장프로그램 사이 메시지를 중계합니다. |
| `popup.html` / `popup.js` | 페이지 연결과 해제, 현재 보고 있는 상품 페이지의 직접 수집. |

## 알아둘 점

- 쿠팡과 1688은 마크업을 자주 바꿉니다. 값이 비어 돌아오면 `scrape.js` 의 선택자 목록을
  실제 페이지 기준으로 갱신해야 합니다. 화면에서 직접 입력해도 계산은 그대로 동작합니다.
- 로그인이나 보안 확인이 필요한 페이지는 크롬에서 먼저 해당 사이트에 접속해 두세요.
- 1688 가격은 수량 구간 중 가장 낮은 값을 가져옵니다. 실제 주문 수량 기준으로 확인 후 수정하세요.
- 수집은 상품 페이지를 여는 방식이므로, 짧은 시간에 많은 링크를 반복 수집하면 사이트가 접근을 제한할 수 있습니다.
