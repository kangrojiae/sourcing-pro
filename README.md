# Sourcing Pro

쿠팡 판매 상품과 1688 소싱 후보를 나란히 놓고 개당 이익금을 계산하는 도구입니다.
키워드 발굴, 쿠팡 노출 순위 수집, 1688 이미지 검색까지 한 흐름으로 이어집니다.

## 구성

| 위치 | 내용 |
| --- | --- |
| `sourcing-pro-app.html` | 앱 전체. 화면, 계산, 저장이 이 파일 하나에 들어 있습니다. |
| `sourcing-pro-extension/` | 크롬 확장프로그램. 쿠팡·1688·네이버에서 값을 가져옵니다. |
| `sourcing-pro.html` | 처음 출발점이 된 디자인 시안입니다. 참고용으로만 두었습니다. |

앱 주소: https://claude.ai/code/artifact/f7a928bd-52ca-4a1d-a03a-dc272f1b365e

## 다른 컴퓨터에서 이어가기

### 1. 앱은 옮길 것이 없습니다

위 주소를 열고 claude.ai에 로그인하면 어느 컴퓨터에서든 그대로 씁니다.
저장된 계정과 비교 기록도 함께 따라옵니다.

### 2. 확장프로그램은 복사해서 다시 넣습니다

1. `sourcing-pro-extension` 폴더를 그 컴퓨터로 복사합니다.
2. 크롬 주소창에 `chrome://extensions` 를 열고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** 를 누르고 그 폴더를 고릅니다.
4. 확장프로그램 아이콘 → **검색광고 API 키 설정** 에서 키를 다시 넣습니다.

API 키는 브라우저 안에만 저장되므로 컴퓨터마다 한 번씩 넣어야 합니다.
1688도 그 컴퓨터의 크롬에서 로그인되어 있어야 이미지 검색이 됩니다.

### 3. 소스 파일을 옮깁니다

이 폴더 전체를 복사해 두세요. 새 컴퓨터에서 Claude Code를 열고 이 폴더를 지정하면
지금까지 만든 코드를 그대로 이어서 고칠 수 있습니다.

앱을 고친 뒤에는 같은 주소로 다시 배포해야 화면에 반영됩니다.
`sourcing-pro-app.html` 을 고치고, Claude Code에서 위 주소로 다시 배포해 달라고 하시면 됩니다.

## 계산식

```
환율 적용 상품가격 = 1688 단가 × 환율
한국도착까지 모든비용 = 환율 적용 상품가격 × 1.45
한국 도착 상품 원가 = 환율 적용 상품가격 + 모든비용
총 지출 = 상품 원가 + (판매가 × 수수료율) + 입출고배송비
이익금 = 판매가 − 총 지출
```

환율은 네이버 금융에서 로그인할 때마다 받아옵니다.
분석마다 환율을 고정하지 않으면, 저장된 모든 기록이 최신 환율로 다시 계산됩니다.
